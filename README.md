# 工科导航

工科大学生职业规划与技能提升项目，包含三个独立模块：

## 项目结构

```
├── content-creator/       # 自媒体内容库（脚本/运营策划）
│   ├── scripts/           #   拍摄脚本（20条示例）
│   └── docs/              #   运营文档（定位/规划/策略/变现）
│
├── xiaohongshu-matrix/    # 小红书矩阵账号管理（8个账号）
│   ├── account-01~08/     #   各账号独立空间（档案/笔记/素材/数据）
│   └── shared/            #   共享模板、标签库、运营SOP
│
└── agent/                 # AI技能测评产品（工科导航Agent）
    ├── frontend/          #   H5前端页面
    ├── api/               #   FastAPI后端接口
    ├── agent/             #   AI核心（Claude API + 评分引擎）
    ├── knowledge/         #   知识库（6专业 + 题库）
    ├── models/            #   数据模型 + 数据库
    └── docs/              #   产品设计文档
```

## 两个模块的关系

```
自媒体内容（抖音/B站/小红书）
        ↓ 引流
AI技能测评（H5页面）
        ↓ 转化
实训营报名（变现）
```

# 工科就业导航 — 自媒体账号运营项目

## 项目概述

本项目是一个专注于 **大学生就业与职业规划** 的自媒体矩阵运营方案，核心定位为：

> **帮助工科大学生家长理解孩子的专业方向、就业前景与成长路径，以实战经验指导职业规划。**

## 主理人背景

- CNC 操机、SMT 设备操机实操经验
- 弱电智能化、数据中心机房及系统集成网络工程 **15 年**从业经历
- 近 **10 年**高校实训室建设经验（网络工程师实训室、物联网实训室、人工智能实训室）
- 工科实训基地主理人，深度了解大学生学习与就业现状

## 平台矩阵

| 平台 | 定位 | 内容形式 |
|------|------|----------|
| 抖音 | 主阵地，流量获取 | 短视频（60s-3min） |
| 视频号 | 微信生态沉淀 | 短视频 + 直播 |
| 小红书 | 深度种草 + 图文 | 图文笔记 + 短视频 |

## 项目结构

## 快速开始

1. 阅读 `docs/01-account-positioning.md` 了解账号定位
2. 参考 `docs/02-content-planning.md` 规划每周选题
3. 使用 `docs/04-script-templates.md` 中的模板撰写脚本
4. 按照 `docs/03-platform-strategy.md` 的节奏发布内容
5. 根据 `docs/05-growth-monetization.md` 推进变现计划

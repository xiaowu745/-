# 工科技能测评 Agent 平台 —— 产品设计文档

## 一、产品定位

### 一句话描述
**「工科导航」**——基于 AI 的工科大学生技能测评与职业发展规划 Agent，帮学生搞清楚"我在哪、该去哪、怎么去"。

### 核心价值
```
┌─────────────────────────────────────────────────────────┐
│                                                         │
│   学生痛点              Agent 解决方案                    │
│                                                         │
│   不知道自己会什么  ──→  技能测评（我在哪）               │
│   不知道该往哪走    ──→  方向推荐（该去哪）               │
│   不知道怎么准备    ──→  学习路径 + 实训推荐（怎么去）     │
│   不知道差距多大    ──→  岗位匹配度评分（差多远）          │
│                                                         │
└─────────────────────────────────────────────────────────┘
```

### 与自媒体内容的闭环关系
```
抖音/视频号/小红书                   Agent 平台
┌──────────────────┐            ┌──────────────────┐
│  内容引流          │   ──→     │  测评入口          │
│  "测测你的技能水平" │            │  生成详细报告      │
│                    │   ←──    │  分享到社交平台     │
│  评论区讨论        │            │  推荐实训课程      │──→ 实训营变现
└──────────────────┘            └──────────────────┘
```

### Module 1：技能测评引擎

#### 1.1 测评维度

```
                    技能雷达图

                  理论基础
                    ╱    ╲
               编程能力 ── 硬件实操
                │              │
               项目经验 ── 工具掌握
                    ╲    ╱
                  职业素养
```

**6大维度 × 每维度5级：**

| 维度 | 评估内容 | L1 入门 | L3 中级 | L5 精通 |
|------|---------|---------|---------|---------|
| 理论基础 | 专业课掌握程度 | 高数/线代及格 | 核心课85分+ | 能推导和应用 |
| 编程能力 | 语言和算法 | Hello World | 独立写中型项目 | 架构设计级别 |
| 硬件实操 | 动手能力 | 认识元器件 | 独立焊接/调试 | 设计完整系统 |
| 工具掌握 | 行业工具链 | 知道名字 | 能独立使用 | 高级功能精通 |
| 项目经验 | 完整项目经历 | 课程作业 | 1-2个完整项目 | 企业级项目 |
| 职业素养 | 软技能 | 能写文档 | 团队协作+汇报 | 带团队+方案设计 |

#### 1.2 测评方式（分层设计）

**第一层：快速自评（3分钟）**
- 20道选择题，覆盖6个维度
- 选项设计为具体场景而非抽象描述
- 示例问题：

```
Q: 关于C语言编程，以下哪个最符合你的现状？

A. 学过但基本忘了，让我写个冒泡排序要查资料
B. 能独立完成课程实验，但没写过超过500行的程序
C. 做过1-2个小项目（如学生管理系统），能独立调试
D. 参加过编程竞赛 / 为开源项目贡献过代码
```

```
Q: 关于网络设备，以下哪个最符合你的情况？

A. 知道交换机和路由器的区别，但没配置过
B. 在模拟器（eNSP/Packet Tracer）上做过实验
C. 在真实设备上配置过VLAN、路由、ACL
D. 能独立设计一个中小企业的网络方案
```

**第二层：AI 深度对话评估（10-15分钟）**
- Agent 根据第一层结果，针对薄弱环节追问
- 通过开放式对话评估真实水平
- 示例对话：

```
Agent: 你提到做过一个物联网项目，能简单描述一下吗？
       用了什么传感器？数据怎么传输的？用什么协议？

学生: 用了DHT11温湿度传感器，通过ESP8266 WiFi模块
      上传到OneNET平台，用的MQTT协议。

Agent: 不错！那MQTT的QoS等级你用的是哪个？为什么选这个？
       数据上报的频率是多少？怎么处理断网重连的？

学生: QoS用的0...断网重连好像没处理...

Agent: [评估：IoT项目经验 L3，协议理解 L2，异常处理 L1]
       没关系，这些都是可以提升的。断网重连是实际项目中
       必须考虑的问题，我可以给你推荐相关的学习资源。
```

**第三层：实操验证题（可选，5-10分钟）**
- 给出实际场景题目，让学生写出解决思路或配置命令
- 不是考试，而是验证自评的准确性

```
场景题示例（网络方向）：
"一家公司有3个部门（行政/技术/财务），共40台电脑。
 要求：部门之间不能互访，但都能上外网。
 请写出你的网络设计思路和关键配置。"

场景题示例（嵌入式方向）：
"用STM32控制一个LED灯：
 按键短按(<1秒)切换开关，长按(>2秒)调节亮度。
 请写出你的实现思路和关键代码片段。"
```

### 4.2 AI Agent 核心设计

```python
# Agent 架构概念

class SkillAssessmentAgent:
    """工科技能测评 Agent 核心"""

    def __init__(self):
        self.tools = [
            QuestionBankTool(),      # 题库查询
            SkillScoringTool(),      # 技能评分
            DirectionMatchTool(),    # 方向匹配
            LearningPathTool(),      # 路径生成
            InterviewSimTool(),      # 面试模拟
            ReportGeneratorTool(),   # 报告生成
        ]

    # Agent 工作流
    #
    # 1. 收集信息阶段
    #    - 专业、年级、基本背景
    #    - 快速自评问卷
    #
    # 2. 深度评估阶段
    #    - 根据自评结果选择追问方向
    #    - 开放式对话验证真实水平
    #    - 可选的实操验证题
    #
    # 3. 分析生成阶段
    #    - 计算6维度得分
    #    - 匹配推荐方向
    #    - 生成学习路径
    #
    # 4. 持续服务阶段
    #    - 学习进度追踪
    #    - 面试模拟
    #    - 实训推荐
```

### 4.3 Prompt 体系设计

```
系统提示词层级：

Level 0: Agent 人设
  "你是「工科导航」的职业规划 AI 助手。
   你的创建者是一位有15年工程经验的实训专家。
   你的目标是帮助工科大学生发现自己的优势和不足，
   找到最适合的职业发展方向。"

Level 1: 专业知识库
  - 各专业的课程体系和就业方向
  - 各岗位的技能要求和薪资数据
  - 考证信息和学习资源

Level 2: 测评逻辑
  - 评分标准和算法
  - 追问策略和对话引导
  - 方向匹配权重

Level 3: 对话风格
  - 不说教、不居高临下
  - 像一个懂行的学长在聊天
  - 客观真实，不画大饼
  - 适当使用鼓励，但不虚夸
```

## 七、与自媒体内容联动策略

### 7.1 引流路径

```
视频内容                          Agent 平台
────────                          ─────────

"物联网是不是天坑？"     ──→    "测测你的物联网技能水平"
（评论区置顶链接）                （小程序码）

"工科最坑的3个专业"     ──→    "你的专业到底坑不坑？AI帮你分析"
（视频末尾口播引导）              （扫码进入测评）

"考研还是就业？"        ──→    "不知道怎么选？先测测你的竞争力"
                                （生成对比报告）
```

### 7.2 内容反哺

```
Agent 产生的数据  ──→  反哺内容创作

例如：
· "85%的网络工程学生不会做水晶头"  ──→  出一条视频讲这个
· "自动化学生最大短板是项目经验"    ──→  出一期"怎么在大学做项目"
· "物联网学生最想了解嵌入式方向"    ──→  出嵌入式系列内容

形成数据驱动的内容策略。
```

### 7.3 报告分享裂变

```
测评报告设计要素：
· 生成精美的分享卡片（适合发朋友圈/抖音）
· 包含学校+专业+综合得分（激发比较心理）
· 底部带小程序码（朋友看到也想测）
· 文案："我在XX大学学XX，工科技能评分XX分，你呢？"

预期效果：
1个用户分享 → 平均带来 3-5 个新测评用户
```

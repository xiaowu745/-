# 内容规划与选题矩阵

## 一、内容四大支柱

```
┌─────────────────────────────────────────────────────┐
│                   内容四大支柱                        │
├──────────┬──────────┬──────────┬────────────────────┤
│  专业解读  │  岗位揭秘  │  实操技能  │  家长必知         │
│   30%    │   25%    │   25%    │      20%          │
└──────────┴──────────┴──────────┴────────────────────┘
```

### 支柱 1：专业解读（30%）
**目标**：帮家长理解孩子的专业到底学什么、能干什么

选题库：
- 「电子信息工程到底学什么？毕业能干啥？」
- 「网络工程 vs 计算机科学，区别在哪？」
- 「物联网工程是不是天坑专业？」
- 「自动化专业的就业方向全解析」
- 「机械设计 vs 机电一体化，怎么选？」
- 「人工智能专业毕业真的能搞AI吗？」
- 「通信工程还值得读吗？2026年实情」
- 「软件工程和计算机科学到底有啥区别？」
- 「数据科学专业毕业都去哪了？」
- 「弱电智能化方向，你可能都没听过，但很缺人」

### 支柱 2：岗位揭秘（25%）
**目标**：让家长和学生真正了解一个岗位的日常、薪资、发展

选题库：
- 「网络工程师的一天是怎么过的？」
- 「CNC操机到底累不累？真实收入多少？」
- 「SMT设备工程师：电子厂里最有技术含量的岗位」
- 「弱电工程师 vs 强电工程师，哪个更有前途？」
- 「系统集成工程师是干什么的？年薪能到多少？」
- 「PLC工程师为什么越老越值钱？」
- 「数据中心运维工程师：996少、稳定、有前途」
- 「嵌入式开发工程师的真实现状」
- 「AI工程师门槛到底有多高？」
- 「项目经理是怎么从技术岗转过来的？」

### 支柱 3：实操技能（25%）
**目标**：展示真实的动手能力训练，让家长看到"学了真的有用"

选题库：
- 「带你看看网络工程师实训室长什么样」
- 「大学生在物联网实训室能学到什么？」
- 「手把手教你做第一个物联网小项目」
- 「AI实训室里的设备值多少钱？」
- 「CNC操机入门：从零件图纸到成品」
- 「网络工程师考证路线图（从CCNA到CCIE）」
- 「弱电智能化项目实操：从布线到调试」
- 「Linux运维入门：大学生必学的10个命令」
- 「交换机配置实操演示」
- 「综合布线实训：你孩子在学校这样练的」

### 支柱 4：家长必知（20%）
**目标**：直接回应家长的焦虑与疑问

选题库：
- 「孩子学工科，家长最该关心的3件事」
- 「工科生考研还是就业？一张表帮你看清」
- 「大学四年，每个阶段该做什么？（工科版）」
- 「孩子说要去工厂实习，该不该支持？」
- 「工科生考什么证最有用？别浪费钱」
- 「为什么你孩子的专业不对口也能就业？」
- 「秋招春招时间线，家长提前帮孩子规划」
- 「实习 vs 考研，大三这个选择怎么做？」
- 「孩子毕业了还没找到工作怎么办？」
- 「工科女生就业到底难不难？」

## 二、内容分层策略

### 流量型内容（40%）— 吸引新关注

特点：话题争议性强、标题有冲击力、容易引发讨论

示例：
- 「工科最坑的3个专业，你孩子中了吗？」
- 「月薪3千和月薪3万的工程师，差在哪？」
- 「90%的工科家长都不知道的就业真相」
- 「这个岗位缺人缺疯了，但大学不怎么教」
- 「你以为的工程师 vs 真实的工程师」

### 信任型内容（35%）— 建立专业权威

特点：干货深度足、逻辑清晰、有数据支撑

示例：
- 「2026年工科各专业就业率+薪资数据解读」
- 「从我带过的500个实训生看：哪种学生最容易就业」
- 「网络工程师职业发展5年规划路线图」
- 「我在高校10年，看到的就业变化趋势」
- 「工科毕业3年/5年/10年薪资天花板在哪？」

### 转化型内容（25%）— 引导行动

特点：提供解决方案、引导私域/课程/咨询

示例：
- 「这个暑假实训营，能让你孩子领先一步」
- 「免费领取：工科考证全路线图」
- 「直播预告：工科就业Q&A专场」
- 「成功案例：从实训到拿到offer的30天」
- 「评论区留专业，我帮你分析就业方向」

## 三、爆款选题公式

### 公式 1：痛点 + 数字 + 身份
```
「工科家长必看的3个就业真相」
「90%的XX专业毕业生不知道的5条出路」
```

### 公式 2：对比 + 反差
```
「你以为的XX vs 真实的XX」
「月薪5千和月薪2万的工程师，就差这一步」
```

### 公式 3：身份权威 + 真实经历
```
「干了15年弱电，我告诉你这行值不值得入」
「在高校带了10年实训，我发现一个规律」
```

### 公式 4：时间节点 + 行动指南
```
「大三暑假还没实习？现在做这3件事还来得及」
「秋招倒计时，工科生的简历该这么写」
```

### 公式 5：问题 + 解答
```
「孩子学网络工程，毕业真的能找到工作吗？」
「物联网工程毕业后都去了哪些公司？」
```

## 四、月度选题排期模板

### 每月 12 条内容（每周 3 条）

| 周次 | 周一 | 周三 | 周五 |
|------|------|------|------|
| 第1周 | 流量型（专业解读） | 信任型（岗位揭秘） | 家长必知 |
| 第2周 | 流量型（热点话题） | 实操技能 | 信任型（数据分析） |
| 第3周 | 流量型（专业解读） | 信任型（岗位揭秘） | 实操技能 |
| 第4周 | 家长必知 | 转化型（引导行动） | 流量型（总结盘点） |

### 季度主题规划

| 季度 | 主题 | 原因 |
|------|------|------|
| Q1（1-3月） | 春招指南 + 考研调剂 | 春招高峰期 |
| Q2（4-6月） | 实习规划 + 毕业季 | 暑期实习招聘 + 毕业季 |
| Q3（7-9月） | 暑期实训 + 秋招备战 | 暑期是实训黄金期 + 秋招启动 |
| Q4（10-12月） | 秋招复盘 + 年度规划 | 秋招尾声 + 新年规划 |

## 五、系列内容规划

### 系列 1：「一分钟看懂XX专业」
- 共 10 期，每期覆盖一个工科专业
- 格式：专业介绍 → 核心课程 → 就业方向 → 薪资参考
- 适合抖音和小红书图文

### 系列 2：「工程师的一天」
- 共 8 期，每期跟拍/模拟一个岗位的日常
- 格式：上班 → 工作内容 → 技术挑战 → 下班
- 适合抖音短视频

### 系列 3：「实训室探秘」
- 共 6 期，每期展示一个实训室
- 格式：设备展示 → 学生操作 → 学到什么 → 对应岗位
- 适合三个平台

### 系列 4：「家长问我答」
- 持续更新，收集评论区问题
- 格式：家长提问 → 专业解答 → 行动建议
- 适合所有平台

### 系列 5：「从校园到职场」
- 共 5 期，讲述真实学生就业案例
- 格式：专业背景 → 实训经历 → 求职过程 → 现在状态
- 适合视频号和小红书

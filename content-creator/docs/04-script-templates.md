# 视频脚本模板

## 一、抖音短视频脚本模板（60-90秒）

### 模板 A：专业解读型

```
【标题】XX专业毕业到底能干什么？

【钩子 - 前3秒】
"你孩子学XX专业？那你知道这个专业毕业后到底能干什么吗？"

【痛点 - 5秒】
"很多家长跟我说，孩子学了四年，自己都说不清楚学的是啥。"

【身份背书 - 5秒】
"我做了15年工程师，又在高校做了10年实训，我来给你说清楚。"

【核心内容 - 40-60秒】
"XX专业的核心课程是……
对口的岗位主要有3个方向：
第一，……月薪大概……
第二，……月薪大概……
第三，……月薪大概……
其中我最推荐的是……因为……"

【行动号召 - 5秒】
"你孩子学什么专业？评论区告诉我，我帮你分析。
关注我，一个讲真话的工科就业导航。"
```

### 模板 G：经验分享型

```
【标题】
在高校做了10年实训，我发现这3类工科生最容易就业

【正文】
💼 做了10年高校实训室建设，带过上千个学生实训，
我发现好就业的工科生都有这3个共同点：

✅ 第一类：动手能力强的
不是说成绩多好，而是愿意动手做项目。
在实训室里，有的学生能连续调试一下午不喊累，
这种学生到了企业就是"来之能战"的人。

✅ 第二类：早规划的
大一大二就开始了解行业，
大三之前就考了对口的证书，
大三暑假就去企业实习了。
这种学生大四根本不用愁。

✅ 第三类：能吃苦、肯下沉的
愿意从基层岗位做起，不好高骛远。
比如我当年从CNC操机做起，
一步一步走到系统集成和项目管理。

❌ 反过来，这3类学生最容易困难：
（简要说明）

📌 家长们，看看你孩子属于哪一类？
评论区告诉我，我帮你出出主意。

#工科就业 #大学生 #职业规划 #实训 #家长
```

## 四、直播脚本框架

### 主题直播：「XX专业就业答疑专场」

```
时长：60分钟

【开场暖场 - 5分钟】
- 自我介绍
- 今天直播的主题
- 引导关注和点赞

【主题分享 - 20分钟】
- XX专业就业市场现状
- 主要就业方向介绍
- 薪资数据分享
- 个人经验和观察

【案例分享 - 10分钟】
- 2-3个真实学生案例
- 从什么专业 → 做了什么准备 → 现在怎么样

【互动答疑 - 20分钟】
- 逐一回答评论区问题
- 针对具体专业给个性化建议
- 引导留言："你孩子什么学校什么专业？打在评论区"

【收尾 - 5分钟】
- 总结今天的核心内容
- 预告下次直播主题
- 引导关注 + 加入粉丝群
```

# 直播脚本：工科就业答疑专场

**平台**：抖音 / 视频号（双平台同步直播）
**时长**：60分钟
**类型**：互动答疑型直播
**适用时间**：周日晚 20:00-21:00

---

## 直播前准备

### 设备清单
- 手机/相机 × 1（主机位）
- 补光灯 × 1
- 麦克风（领夹麦或桌面麦）
- 手机支架/三脚架
- 白板或iPad（用于画图解释）

### 场景布置
- 背景：实训室或书架前（展示专业感）
- 桌上摆放：几本技术书、网络设备（如交换机模块）、证书
- 打光：面光为主，避免背光

### 直播间设置
- 标题：「工科就业答疑专场｜你的专业能干什么？问我」
- 封面：个人照片 + "15年工程师在线答疑"
- 提前1天发预告视频/图文

---

## 直播流程

### 第一段：开场暖场（0:00 - 5:00）

```
大家好，欢迎来到直播间！
我是[名字]，做了15年的工程师，也在高校做了10年的实训室建设。

今天是我们的工科就业答疑专场——
不管你的孩子学什么工科专业，不管大几，
有任何关于就业、考研、考证、职业规划的问题，都可以打在评论区。

在等人进来的时候，先做个自我介绍：
（简要介绍自己的背景：CNC → SMT → 弱电/网络 → 实训室建设）

点个关注不迷路，后面每周/每两周都会做这样的答疑直播。
先点点赞，让更多需要的家长看到这个直播间。
```

**互动引导**：
- "你孩子学什么专业？打在评论区"
- "哪个城市的？学什么学校？"
- 前5分钟以互动热场为主，不急着讲干货

---

### 第二段：主题分享（5:00 - 25:00）

**本期主题：工科各专业就业方向快速总览**

```
好，人来得差不多了，我们开始今天的主题。

今天给大家快速过一下主要工科专业的就业方向，
每个专业我用2-3分钟讲清楚。

评论区有说孩子学XX的，我们就从XX开始。
```

**按评论区提问顺序，从以下专业中选讲（每个2-3分钟）：**

1. **计算机科学/软件工程**
   - 开发（前端/后端/全栈）
   - 运维/DevOps
   - 测试
   - 薪资范围 + 建议

2. **网络工程**
   - 企业网 / 数据中心 / 安全
   - 考证路线
   - 薪资范围 + 建议

3. **电子信息工程**
   - 硬件 / 嵌入式 / 射频 / 电子制造
   - 薪资范围 + 建议

4. **自动化/电气**
   - PLC / 电气 / 机器人 / 嵌入式
   - 薪资范围 + 建议

5. **物联网**
   - 嵌入式 / IoT平台 / 系统集成
   - 薪资范围 + 建议

6. **机械/机电**
   - CNC / 机械设计 / 质量
   - 薪资范围 + 建议

**穿插互动**：
- 每讲完一个专业，问："有学这个的吗？还有什么想了解的？"
- 看到好的评论可以念出来回应

---

### 第三段：重点话题深入（25:00 - 40:00）

**根据评论区热度，选1-2个话题深入聊：**

备选话题：
- "考研还是就业"（如果很多人问）
- "孩子大三了还没实习怎么办"
- "XX证书值不值得考"
- "从我的经历聊聊：技术转管理的路径"
- "实训到底有没有用？跟培训班有什么区别？"

```
我看评论区很多人在问XXX，这个话题展开聊一下。

（深入讲解15分钟，可以用白板画图辅助说明）

我给大家的建议是……
```

**互动技巧**：
- 点名回复具体用户："那个XXX的家长问的问题很好"
- 用"让我把这个问题展开说一下"来延伸内容
- 如果不确定的问题，诚实说"这个我不太确定，我回头查一下给你回复"

---

### 第四段：快速答疑（40:00 - 55:00）

```
好，接下来我们进入快速答疑环节。
评论区的问题我一个一个回答，来吧！
```

**答疑节奏**：
- 每个问题用30秒-2分钟快速回答
- 遇到复杂问题说："这个展开说需要一整条视频，我后面单独出一期"
- 遇到重复的问题："这个刚才讲过了，没看到的翻一下回放"

**常见问题及简要回答方向**：

Q："孩子大一，现在该做什么？"
A：打好基础课 + 找到实训室/实验室 + 不用急着考证

Q："XX专业是不是天坑？"
A：没有天坑专业，只有没规划好的大学四年

Q："孩子想转专业怎么办？"
A：先搞清楚想转的方向就业怎么样，别从一个坑跳到另一个坑

Q："考公还是进企业？"
A：工科考公选择少但竞争也小，进企业成长快但不稳定——看个人追求

Q："二本/三本工科有出路吗？"
A：绝对有。工科看能力不看出身，证书+项目经验>学校名气

---

### 第五段：收尾（55:00 - 60:00）

```
好，今天的直播差不多要到时间了。
感谢大家的陪伴！今天在线的家长和同学们都非常积极。

快速总结一下今天的核心内容：
1. ……
2. ……
3. ……

没回答到的问题不用急，有两个渠道：
1. 关注我，后续视频会覆盖更多专业和岗位
2. 评论区留言或私信，我看到会回复

下次直播预告：
下周（或两周后）同一时间，主题是「XX」，到时候准时来！

最后帮我点个关注、点个赞。
有帮助的话分享给身边有工科孩子的家长，帮到更多人。
谢谢大家，我们下次见！
```

## 直播后跟进

### 当天
- [ ] 保存直播回放
- [ ] 从直播中剪辑2-3个精彩片段，作为短视频发布
- [ ] 回复直播中没来得及回答的问题

### 次日
- [ ] 发一条感谢帖/视频："昨天直播太火爆了，这些问题我补充回答一下"
- [ ] 统计直播数据（观看人数、峰值在线、新增粉丝、互动量）
- [ ] 根据问题热度规划下周视频选题

### 剪辑短视频示例
- 片段1：某个专业的2分钟就业解析 → 发抖音
- 片段2：回答某个家长问题的精彩片段 → 发视频号
- 片段3：总结性金句 → 做成小红书图文

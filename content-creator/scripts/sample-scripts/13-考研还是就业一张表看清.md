# 脚本：工科生考研还是就业？一张表帮你看清

**平台**：抖音（主） / 视频号 / 小红书
**时长**：90秒（抖音） / 4分钟（视频号）
**类型**：家长必知 · 决策指导型
**系列**：独立选题 / 高互动型内容

---

## 抖音版脚本（90秒）

**【钩子 - 3秒】**

"孩子大三了，考研还是就业？一张表帮你看清。"

**【痛点共鸣 - 10秒】**

"这个问题是我被问得最多的。
每年到大三，家长群里都在吵——
有人说'一定要考研，本科不值钱了'，
也有人说'早就业早挣钱，别浪费时间'。
到底怎么选？其实不能一概而论。"

**【对比分析 - 50秒】**

"我按照工科不同情况，帮你对比一下：

情况一：如果目标是进大厂、研究所、高校。
答案很明确——考研。
华为、中兴、航天院所这些单位，很多岗位硬性要求硕士。
考研是必经之路，没得选。

情况二：如果目标是做工程师、走技术路线。
比如网络工程师、PLC工程师、弱电工程师、系统集成。
这些岗位——经验比学历重要。
早工作3年积累的项目经验，比读研3年写论文更有竞争力。
我身边年薪30万以上的工程师，大部分是本科直接工作的。

情况三：如果本科学校一般、想提升平台。
考研是跳板——考到985/211，校招资源完全不同。
但前提是你能考上目标校，不是随便考一个。

情况四：如果不知道自己想干什么，先考个研'缓一缓'。
这是最危险的。
考研不是逃避就业的避风港。
很多人研究生读完还是不知道干什么，但已经大了3岁。"

**【决策框架 - 15秒】**

"给你一个简单的判断方法：

选考研：目标岗位要求硕士 / 想进研究所大厂 / 想换学校平台
选就业：目标岗位看经验不看学历 / 家庭经济需要早工作 / 已经有明确的技术方向

最怕的是：既没想清楚就去考研，又没好好准备就去找工作。
不管选哪个，想清楚了全力以赴。"

**【行动号召 - 5秒】**

"你孩子什么专业？考研还是就业在纠结？评论区告诉我，帮你分析。"

## 视频号扩展版补充内容

**【详细对比表 - 60秒】**

"给大家一个更详细的对比：

时间成本：
考研——准备1年 + 读研2-3年，总共3-4年
就业——大四秋招即开始，1年内完成过渡

经济成本：
考研——学费+生活费，3年大约花费8-15万（家庭承担）
就业——立即开始挣钱，3年累计收入15-30万

就业起薪（以网络工程为例）：
本科直接就业——起薪6000-8000，3年后8000-15000
硕士毕业就业——起薪8000-12000，但少了3年经验

长期发展：
考研——学历敲门砖，部分岗位晋升有学历要求
就业——经验积累快，技术岗位中经验>学历

你看，没有绝对的对错。
关键看你孩子的目标岗位和个人情况。"

**【按专业具体建议 - 60秒】**

"按专业给你具体建议：

计算机/软件工程：
如果想进互联网大厂 → 考研，尤其985/211
如果想做开发工程师 → 先就业也可以，能力比学历重要

网络工程：
不推荐考研。这个方向非常看实操经验。
HCIP证书 + 3年经验 > 硕士 + 0经验。
除非你想做网络安全研究方向。

自动化/电气：
如果想进国网、中建、航天系统 → 必须考研
如果想做PLC工程师、自动化集成 → 不需要考研

电子信息/通信：
如果想做芯片设计、射频 → 几乎必须考研
如果想做硬件测试、电子制造 → 不需要考研

物联网：
看方向。做嵌入式开发可以先就业，做AI研究需要考研。

弱电智能化/系统集成：
不需要考研。这个行业完全看项目经验和证书。
我干了15年，从来没有甲方问过我什么学历。"

**【给犹豫不决的家长 - 40秒】**

"如果到现在还拿不定主意，我给你一个'笨办法'：

1. 让孩子大三暑假先去实习一次。
   感受一下真实的工作环境，回来再做决定。
   很多学生实习完之后就想清楚了。

2. 同时准备不冲突。
   大三上学期开始准备考研的同时，让孩子投简历、做项目。
   如果考上了好学校就去读，考不上也不耽误就业。
   怕的是孤注一掷考研，二战三战，越拖越被动。

3. 跟孩子好好聊一次。
   不是你帮他选，是引导他自己想清楚：
   '你以后想做什么工作？那个工作需要研究生学历吗？'
   问这两个问题，答案就出来了。"

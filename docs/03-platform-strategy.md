# 平台策略与发布计划

## 一、三平台差异化策略

### 抖音 — 主阵地（流量引擎）

| 维度 | 策略 |
|------|------|
| 定位 | 短平快获取新流量，建立认知 |
| 内容形式 | 口播为主（60s-90s），穿插实训室实拍 |
| 发布频率 | 每周 3-4 条 |
| 最佳发布时间 | 工作日 12:00-13:00 / 20:00-21:30 |
| 核心玩法 | 热点话题蹭流量 + 评论区互动 + 合拍/对口型 |
| 账号权重提升 | 坚持日更30天 → 稳定周更3条 |

**抖音运营要点**：
1. 前3秒必须有钩子（痛点提问/震惊数据/反常识观点）
2. 字幕必须加，家长刷视频常静音
3. 评论区置顶引导语："你孩子什么专业？评论区告诉我"
4. 善用抖音话题标签：#工科就业 #大学生职业规划 #家长必看
5. 直播：每周/双周一次，Q&A形式，30-60分钟

### 视频号 — 信任沉淀（私域入口）

| 维度 | 策略 |
|------|------|
| 定位 | 深度内容 + 微信私域导流 |
| 内容形式 | 口播 + 长视频（3-8min），直播 |
| 发布频率 | 每周 2-3 条（与抖音内容可复用） |
| 最佳发布时间 | 工作日 7:30-8:30 / 20:00-21:00 |
| 核心玩法 | 社交推荐（家长转发到班级群/家长群） |
| 私域路径 | 视频号 → 公众号 → 企业微信/社群 |

**视频号运营要点**：
1. 内容偏深度和实用，家长会转发给孩子或其他家长
2. 标题直接写清楚价值："XX专业毕业能干什么？3分钟讲清楚"
3. 评论区引导关注公众号获取更多资料
4. 利用微信生态的社交传播优势
5. 直播：每月 2-4 次，主题式直播（如"电子信息类专业就业全解"）

### 小红书 — 种草转化（精准触达）

| 维度 | 策略 |
|------|------|
| 定位 | 图文深度种草 + 精准搜索流量 |
| 内容形式 | 图文笔记为主，辅以短视频 |
| 发布频率 | 每周 3-4 篇 |
| 最佳发布时间 | 工作日 12:00-14:00 / 19:00-21:00 |
| 核心玩法 | SEO 关键词覆盖 + 收藏型干货 |
| 变现路径 | 笔记种草 → 私信咨询 → 付费课程/实训营 |

**小红书运营要点**：
1. 标题必须包含搜索关键词（如"网络工程就业""工科考研还是就业"）
2. 封面图用信息图/数据图/对比图，高保存率
3. 内容结构化：分点、加粗、用表情符号分段
4. 图文比视频更容易获得搜索流量
5. 多用"收藏夹"类内容：路线图、考证清单、薪资表

## 二、内容复用策略

### 一鱼多吃：一个选题产出多条内容

```
                    ┌─→ 抖音短视频（60-90s口播精华版）
                    │
一个选题（例如：     ├─→ 视频号中长视频（3-5min深度版）
网络工程师就业解析） │
                    ├─→ 小红书图文笔记（信息图+文字版）
                    │
                    └─→ 小红书短视频（竖版，同抖音或重新剪辑）
```

### 具体复用流程

1. **先录制完整版**（5-8分钟，覆盖完整内容）
2. **剪辑抖音版**：提取最精华的60-90秒
3. **剪辑视频号版**：保留3-5分钟的中等长度
4. **提炼图文版**：核心信息做成小红书图文笔记
5. **提炼金句**：用于评论区、社群、朋友圈

## 六、冷启动30天计划

### 第1周：基础搭建
- [ ] 三个平台完成账号注册和资料完善
- [ ] 确定账号名称、头像、简介
- [ ] 拍摄5条以上的储备视频
- [ ] 发布第1条自我介绍视频

### 第2周：内容测试
- [ ] 每天发布1条视频（测试不同方向）
- [ ] 记录每条视频的播放、点赞、评论数据
- [ ] 分析哪个方向的数据最好
- [ ] 开始回复每一条评论

### 第3周：方向确认
- [ ] 根据数据确定主打内容方向
- [ ] 开始做系列内容（如"一分钟看懂XX专业"）
- [ ] 每天保持发布
- [ ] 加入同领域创作者社群学习

### 第4周：节奏稳定
- [ ] 从日更过渡到稳定的周更节奏（3-4条/周）
- [ ] 尝试第一次直播
- [ ] 总结30天数据，调整策略
- [ ] 规划下月内容选题

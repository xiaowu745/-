# 账号定位与品牌规划

| 方案 | 名称 | 理由 |
|------|------|------|
| A | **工科老爸说就业** | 亲切感强，家长视角，突出工科 |

## 二、账号定位公式

```
谁（Who）：工科实训基地主理人，15年弱电/网络工程一线经验 + 10年高校实训室建设经验
给谁看（For Whom）：工科大学生的家长（核心），其次是大学生本人
解决什么问题（Problem）：
  - 家长不了解孩子学的专业到底能干什么
  - 不知道哪些方向就业好、薪资高
  - 担心孩子毕业即失业
  - 不了解实习/考证/技能提升的路径
怎么解决（How）：用一线工程师 + 高校实训的双重视角，讲真话、说实话
```

## 三、人设定位

### 核心人设：**懂技术、懂教育的工科实战派**

| 维度 | 定义 |
|------|------|
| 专业身份 | 工科实训基地主理人 |
| 技术背景 | CNC操机 → SMT设备 → 弱电智能化/数据中心/网络工程15年 |
| 教育背景 | 高校实训室建设10年（网络工程、物联网、AI实训室） |
| 说话风格 | 务实、直接、不画饼、用数据和案例说话 |
| 核心标签 | #工科就业 #职业规划 #实训实操 #工程师成长 |

### 差异化优势

1. **双重身份**：既是一线技术人，又深入高校教学——市面上极少见
2. **真实案例**：能讲出"学了什么 → 干了什么 → 挣了多少"的完整链路
3. **家长视角**：用家长听得懂的语言解释技术行业
4. **实操导向**：不空谈理论，强调动手能力和实际技能

## 四、目标受众画像

### 核心受众：工科大学生家长

| 特征 | 描述 |
|------|------|
| 年龄 | 45-55 岁 |
| 身份 | 大学生（大一到大四）的父母 |
| 痛点 | 不懂技术行业，焦虑孩子就业前景 |
| 信息来源 | 抖音、微信（视频号）、小红书、家长群 |
| 决策影响 | 对孩子的考证、实习、考研等决策有重要影响 |
| 消费能力 | 愿意为孩子的职业培训/实训课程付费 |

### 次要受众：工科大学生本人

| 特征 | 描述 |
|------|------|
| 年龄 | 18-23 岁 |
| 身份 | 工科在校生（电子、计算机、自动化、通信、机械等） |
| 痛点 | 不知道学的东西有什么用、不知道该往哪个方向发展 |
| 需求 | 真实的行业信息、实操技能学习路径、就业指导 |

## 五、覆盖的工科专业与对应岗位

| 专业大类 | 具体专业 | 对口岗位方向 |

| 计算机 | 计算机科学、软件工程、网络工程 | 软件开发、网络工程师、运维工程师、安全工程师 |

3. **CNC 操机/编程** — 制造业方向
4. **SMT 设备工程师** — 电子制造方向
5. **物联网工程师** — IoT 应用方向
6. **AI 应用工程师** — 人工智能落地方向

## 七、账号视觉建议

### 头像
- 穿工装/polo衫，背景为实训室或机房环境
- 体现专业感与亲和力

### 封面/背景图
- 主色调：深蓝 + 橙色（科技感 + 活力）
- 包含关键词：工科就业 | 职业规划 | 实训实操
- 展示实训室/设备照片

### 视频封面模板
- 统一风格：大字标题 + 专业分类标签
- 示例：「网络工程师月薪多少？」「CNC操机值不值得学？」

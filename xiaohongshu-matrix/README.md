# 小红书矩阵账号管理

8个小红书矩阵账号的内容管理系统，以图文笔记为主。

## 目录结构

```
xiaohongshu-matrix/
├── account-01/                # 账号01（待定位）
│   ├── profile/               #   账号档案（定位、人设、标签）
│   │   └── README.md          #   账号信息卡
│   ├── notes/                 #   笔记内容
│   │   ├── drafts/            #     草稿箱
│   │   ├── published/         #     已发布（按月归档）
│   │   └── templates/         #     该账号专属模板
│   ├── assets/                #   素材资源
│   │   ├── covers/            #     封面图
│   │   └── images/            #     正文配图
│   └── data/                  #   数据记录
├── account-02/ ~ account-08/  # 同上结构
│
└── shared/                    # 共享资源
    ├── templates/             #   通用模板
    │   ├── account-profile.md #     账号档案模板
    │   └── note-template.md   #     图文笔记模板
    ├── tags/                  #   标签库（按领域分类）
    ├── sop/                   #   运营SOP
    │   └── daily-workflow.md  #     日常运营流程
    └── assets/                #   公共素材（logo、水印等）
```

## 使用方法

### 1. 填写账号档案

编辑各账号的 `profile/README.md`，填入：
- 账号名称和定位
- 人设设定和说话风格
- 内容支柱和发布频率
- 变现路径和数据目标

### 2. 创建笔记内容

```bash
# 在对应账号的 drafts 目录下创建新笔记
# 命名规则：日期-标题.md
# 例如：2026-03-22-网络工程师入行攻略.md
```

从 `notes/templates/note-template.md` 复制模板，填入内容。

### 3. 发布流程

1. 在 `drafts/` 创作内容
2. 审核通过后发布到小红书
3. 将文件移动到 `published/` 并记录发布日期
4. 发布后在笔记底部的数据表中跟踪效果

### 4. 矩阵协同

- 各账号间可通过 `关联账号` 字段标记互推关系
- 共享素材放在 `shared/assets/`
- 通用标签库维护在 `shared/tags/`

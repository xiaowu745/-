# 小红书矩阵日常运营 SOP

## 每日流程

### 1. 早间（8:00-9:00）
- [ ] 检查各账号昨日数据（阅读/互动/涨粉）
- [ ] 回复各账号评论和私信
- [ ] 查看热搜/热门话题，记录可蹭的热点

### 2. 上午（9:00-12:00）
- [ ] 创作当日笔记内容（文案撰写）
- [ ] 制作配图/封面

### 3. 下午（12:00-14:00 / 19:00-21:00 发布窗口）
- [ ] 按计划发布笔记
- [ ] 发布后30分钟内回复前几条评论（提升初始互动）

### 4. 晚间（21:00-22:00）
- [ ] 浏览同领域优质内容，收集选题灵感
- [ ] 更新内容日历，安排次日任务

## 每周流程

- [ ] 周一：制定本周8个账号的发布计划
- [ ] 周五：统计本周各账号数据，填入数据表
- [ ] 周日：复盘本周内容表现，调整下周策略

## 每月流程

- [ ] 月初：设定各账号月度目标
- [ ] 月中：检查进度，必要时调整策略
- [ ] 月末：月度数据复盘 + 爆款分析
